## [<<](./readme.md) Техническое задание №12

### Реализация CQRS-команды для удаления заказа

### Цель
Реализовать полный цикл CQRS для удаления заказа по ID: создать команду, обработчик, валидатор и HTTP-эндпоинт.

### Требования к реализации

1. **Создать Command**
   - Описать класс команды `DeleteOrderCommand`, реализующий интерфейс `ICommand`.
   - Параметр команды — строка `OrderId`.

2. **Создать Handler**
   - Реализовать обработчик `DeleteOrderCommandHandler`, который удаляет заказ через репозиторий `IOrderRepository`.
   - Обработчик должен проверять существование заказа и выбрасывать `NotFoundException` если заказ не найден.
   - Возвращать результат в виде `DeleteOrderResult` с флагом успешности удаления.

3. **Создать валидатор**
   - Реализовать валидатор `DeleteOrderCommandValidator` для проверки корректности GUID в строковом формате.

4. **Реализовать эндпоинт**
   - Добавить HTTP-эндпоинт `DELETE /orders/` с параметром OrderId.
   - Эндпоинт должен возвращать 200 (Ok) при успешном удалении или 404 (NotFound) если заказ не найден.
   - Использовать Carter-модуль для организации маршрута.

#### Дополнительно
- Все методы должны быть реализованы асинхронно.
- Соблюдать принципы чистой архитектуры и разделения ответственности.
- Использовать валидацию через FluentValidation в MediatR pipeline.
