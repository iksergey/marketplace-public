## [<<](./readme.md) Техническое задание №1

### Реализация методов CatalogRepository с использованием Marten

### Цель
Дописать реализацию методов в классе `CatalogRepository`, используя библиотеку Marten для работы с базой данных.

### Требования к реализации

1. **Внедрение зависимостей**
   - Внедрить зависимость `IDocumentSession` для работы с Marten.

2. **Реализация методов**
   - Для каждого метода использовать асинхронные операции Marten.

3. **Используемые интерфейсы**
   - Класс должен реализовывать интерфейсы: `IBrandRepository`, `ICategoryRepository`, `ICatalogItemRepository`.

4. **Регистрация сервисов**
   - Внедрить зависимости в DI-контейнер.

#### Дополнительно
- Необходимо убедиться, что все зависимости корректно зарегистрированы в DI-контейнере.
- Все методы должны быть реализованы асинхронно.
- В коде использовать только возможности библиотеки Marten для работы с данными.
