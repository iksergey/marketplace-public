## [<<](./readme.md) Техническое задание №6

### Реализация CQRS-команды для удаления корзины по accountName

### Цель
Реализовать полный цикл CQRS для удаления корзины пользователя по имени аккаунта: создать команду, обработчик, модели и HTTP-эндпоинт.

### Требования к реализации

1. **Команда (Command)**
   - Описать класс команды `RemoveCartCommand`, реализующий интерфейс `ICommand`.
   - Параметр команды — строка `AccountName`.

2. **Обработчик (Handler)**
   - Реализовать обработчик `RemoveCartHandler`, который удаляет корзину через репозиторий `ICartRepository`.
   - Обработчик должен быть асинхронным и возвращать результат в виде `RemoveCartResult`.

3. **Модели запроса и ответа**
   - Описать классы для API: `RemoveCartRequest` и `RemoveCartResponse`.

4. **Эндпоинт**
   - Добавить HTTP-эндпоинт `/cart/{accountName}` с методом DELETE.
   - Эндпоинт должен принимать `accountName`, отправлять команду через MediatR и возвращать результат с HTTP-статусом 200 (Ok).
   - Описать эндпоинт с помощью Carter-модуля и добавить аннотации для Swagger (имя, summary, description, типы ответов).

5. **Валидатор**
   - Реализовать валидатор `RemoveCartCommandValidator` для проверки, что `AccountName` не пустой.

#### Дополнительно
- Все методы и обработчики должны быть реализованы асинхронно.
- Соблюдать принципы чистой архитектуры и разделения ответственности.
- Использовать только возможности MediatR и Carter для организации команд, обработчиков и маршрутов.
- В контроллере или модуле использовать внедрение зависимостей через DI-контейнер.
