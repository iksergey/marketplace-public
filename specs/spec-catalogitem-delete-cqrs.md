## [<<](./readme.md) Техническое задание №3

### Реализация CQRS-команды для удаления товара из каталога

### Цель
Реализовать полный цикл CQRS для удаления товара по идентификатору: создать команду, обработчик, ответ и endpoint в контроллере.

### Требования к реализации

1. **Создать Command**
   - Описать класс команды `DeleteCatalogItemByIdCommand`, реализующий интерфейс `IRequest`.

2. **Создать Handler**
   - Реализовать обработчик `DeleteCatalogItemByIdHandler`, принимающий зависимость `ICatalogItemRepository`.
   - В обработчике:
     - Проверить, существует ли товар с указанным Id.
     - Если не найден — вернуть результат с `IsSuccess = false`.
     - Если найден — удалить товар через репозиторий и вернуть результат с соответствующим значением `IsSuccess`.

3. **Создать Response**
   - Описать класс ответа `DeleteCatalogItemByIdResult`, содержащий булево свойство `IsSuccess` (успешно ли выполнено удаление).

4. **Реализовать контроллер**
   - Добавить endpoint в контроллере (например, `CatalogItemController`) с методом `DeleteCatalogItem`, принимающим Id из маршрута.
   - Endpoint должен отправлять команду через MediatR и возвращать результат с HTTP-статусом 200 (Ok).

5. **Регистрация зависимостей**
   - Убедиться, что все обработчики и зависимости зарегистрированы в DI-контейнере.

#### Дополнительно
- Все методы должны быть реализованы асинхронно.
- Соблюдать чистую архитектуру и разделение ответственности.
- Использовать только возможности MediatR для организации команд и обработчиков.
- В контроллере использовать базовый класс с ленивым получением IMediator, если это предусмотрено архитектурой.
