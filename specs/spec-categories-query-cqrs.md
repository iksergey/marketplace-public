## [<<](./readme.md) Техническое задание №2

### Реализация CQRS-запроса для получения категорий

### Цель
Реализовать полный цикл CQRS для получения списка категорий: создать запрос, обработчик, ответ и контроллер.

### Требования к реализации

1. **Создать Query**
   - Описать класс запроса `GetCategoriesQuery`, реализующий интерфейс `IRequest`.

2. **Создать Handler**
   - Реализовать обработчик `GetCategoriesQueryHandler`, который получает все категории через репозиторий `ICategoryRepository`.
   - Обработчик должен быть асинхронным и возвращать результат в виде `GetCategoriesResult`.

3. **Создать Response**
   - Описать класс ответа `GetCategoriesResult`, содержащий коллекцию объектов `Category`.

4. **Реализовать контроллер**
   - Добавить контроллер `CategoriesController` с методом `GetCategories`, который отправляет запрос через MediatR и возвращает результат с HTTP-статусом 200 (Ok).

5. **Регистрация зависимостей**
   - Убедиться, что все обработчики и зависимости зарегистрированы в DI-контейнере.

#### Дополнительно
- Все методы должны быть реализованы асинхронно.
- Соблюдать чистую архитектуру и разделение ответственности.
- Использовать только возможности MediatR для организации запросов и обработчиков.
- В контроллере использовать базовый класс с ленивым получением IMediator, если это предусмотрено архитектурой.
