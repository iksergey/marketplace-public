## [<<](./readme.md) Техническое задание №5

### Реализация CQRS-запроса для получения корзины по accountName

### Цель
Реализовать полный цикл CQRS для получения корзины пользователя по имени аккаунта: создать запрос, обработчик, модели и HTTP-эндпоинт.

### Требования к реализации

1. **Запрос (Query)**
   - Описать класс запроса `RetrieveCartQuery`, реализующий интерфейс `IQuery`.
   - Параметр запроса — строка `AccountName`.

2. **Обработчик (Handler)**
   - Реализовать обработчик `RetrieveCartQueryHandler`, который получает корзину через репозиторий `ICartRepository`.
   - Обработчик должен быть асинхронным и возвращать результат в виде `RetrieveCartResult`.

3. **Модели запроса и ответа**
   - Описать классы запроса и ответа для API: `RetrieveCartRequest` и `RetrieveCartResponse`.

4. **Эндпоинт**
   - Добавить HTTP-эндпоинт `/cart/{accountName}` с методом GET.
   - Эндпоинт должен принимать `accountName`, отправлять запрос через MediatR и возвращать результат с HTTP-статусом 200 (Ok).
   - Описать эндпоинт с помощью Carter-модуля и добавить аннотации для Swagger (имя, summary, description, типы ответов).

#### Дополнительно
- Все методы и обработчики должны быть реализованы асинхронно.
- Соблюдать принципы чистой архитектуры и разделения ответственности.
- Использовать только возможности MediatR и Carter для организации запросов, обработчиков и маршрутов.
- В контроллере или модуле использовать внедрение зависимостей через DI-контейнер.
