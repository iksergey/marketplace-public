## [<<](./readme.md) Техническое задание №13

### Реализация CQRS-команды для обновления заказа

### Цель
Реализовать полный цикл CQRS для частичного обновления заказа: создать команду, обработчик, валидатор, маппинг и HTTP-эндпоинт с поддержкой обновления отдельных полей.

### Требования к реализации

1. **Создать Command**
   - Описать класс команды `UpdateOrderCommand`, реализующий интерфейс `ICommand`.
   - Параметры команды — строка `OrderId` и объект `UpdateOrderDto` с опциональными полями.

2. **Создать DTO модели**
   - Реализовать `UpdateOrderDto` с nullable полями для частичного обновления:
     - `ContactInfo` (опционально)
     - `DeliveryAddress` (опционально)  
     - `PaymentMethod` (опционально)
     - `CardDetails` (опционально)
     - `Status` (опционально)

3. **Создать Handler**
   - Реализовать обработчик `UpdateOrderCommandHandler`, который находит существующий заказ и обновляет только переданные поля.
   - Обработчик должен выбрасывать `NotFoundException` если заказ не найден.

4. **Создать валидатор**
   - Реализовать валидатор `UpdateOrderCommandValidator` с проверками на своё усмотрение.

5. **Настроить маппинг**
   - Создать `UpdateOrderMappingConfig` с конфигурацией для обновления существующего Order.

6. **Реализовать эндпоинт**
   - Добавить HTTP-эндпоинт `PUT /orders` для обновления заказа.
   - Эндпоинт должен возвращать 200 (Ok) при успешном обновлении или 404 (NotFound) если заказ не найден.
