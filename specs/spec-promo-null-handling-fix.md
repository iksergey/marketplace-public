## [<<](./readme.md) Техническое задание №9

### Исправление обработки отсутствующих промо-акций в gRPC-сервисе

### Проблема

При запросе промо-акций для товаров, которых нет в базе данных, микросервис Basket получает 500-ю ошибку из-за выбрасывания `RpcException` в промо-сервисе. Это приводит к падению обработки всей корзины, когда хотя бы для одного товара отсутствует промо-акция.

**Текущее поведение:**
- Товары 1, 2, 5 имеют скидки в БД
- Товар 3 не имеет скидки 
- При обработке корзины с товаром 3 возникает исключение
- Весь процесс сохранения корзины прерывается

### Задача

Необходимо исправить логику обработки отсутствующих промо-акций, чтобы обеспечить стабильную работу микросервиса `Basket.Api` при запросе скидок для товаров, которых нет в базе данных `Promotion`-сервиса.

### Ожидаемый результат

- Корзина обрабатывается полностью даже при отсутствии промо-акций для некоторых товаров
- Товары без скидок остаются с исходной ценой
- Отсутствие 500-х ошибок при работе с корзиной
